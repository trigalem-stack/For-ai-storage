# For-ai-storage — плагины для Minecraft

* В корне репозитория — **оригинальные** jar-плагины, собранные под Paper/Spigot **1.21.4** (не изменялись).
* [`1.21.11/`](1.21.11/) — **готовые плагины для Paper 1.21.11**: 18 jar, `README.md`, `TEST-REPORT.md`, `SHA256SUMS.txt`.
* [`Paper-1.21.11-plugins.zip`](Paper-1.21.11-plugins.zip) — архив со всеми готовыми плагинами для 1.21.11.
* [`Astrummc-1.21.11.zip`](Astrummc-1.21.11.zip) — ресурс-пак `Astrummc` (3D-модели, 2D-текстуры, шрифты, звуки),
  перепортированный с формата 45 (1.21.4) на формат **75 (1.21.11)**. Все числовые `custom_model_data` без изменений.
  Подробности — в [`Astrummc-1.21.11.md`](Astrummc-1.21.11.md).

Код плагинов не менялся: все class-файлы в новых jar байт-в-байт совпадают с оригиналами.
Обновлены только `api-version` и `version` в `plugin.yml`/`pom.xml`.
Проверено на реальном Paper 1.21.11-111-main@302c47c (Java 25): все 18 плагинов загрузились и работают.

Подробности и команды — в [`1.21.11/README.md`](1.21.11/README.md).
